Keys and mouse

In the 3D view

Action How

Rotate

Left-drag, starting on empty background

Pan

Middle-drag

Zoom about the pointer

Mouse wheel

Select

Left-click an object

Clear the selection

Left-click empty space

Stop a rotate or pan where it is

Esc while dragging

Fit everything in view

Ctrl+E with the pointer over the 3D view, or View ▸ Zoom Extents

Anywhere

Key What it does

W

Opens the Waypoints panel (not while typing in a field)

Alt+F, Alt+E, Alt+V, Alt+H

Open the File, Edit, View and Help menus

Alt+F4

Closes FRobot, asking first about unsaved solutions

Ctrl+click on Pick & Place Tech

Discards the solution and keeps the 3D part

In panels and dialogs

Key What it does

Enter

Applies the typed numbers

Esc

Throws the typed numbers away

Tab, Shift+Tab

Next or previous number field

Shift + an arrow beside a field

A smaller step

Esc or Enter in a dialog card

Closes it as Cancel / No

Double-click the header of a small panel (Waypoints, Gripper, Pickup, Centering, Deposit, Regrip)

Folds or unfolds the panel

Apart from Ctrl+E, the shortcuts shown in the menus (Ctrl+O, Ctrl+S, Ctrl+Z, F4, F1 …) do not work in this version.

File types

File What it is Open with Saved by

.fr

A solution: cell, part, gripper and cycle

File ▸ Open…​, the recent files, double-click

File ▸ Save, Save As…​

.curl

A cell config

File ▸ Open…​, the robot selector

File ▸ Save Cell Config

.dxf, .geo

A part’s flat drawing

File ▸ Open…​, add ▸ 2D Sheet (DXF / GEO)

.step, .stp

A STEP model: a cell element or an obstacle part

add ▸ Cell Component (File), settings ▸ Part ▸ Import Part…

.stl, .obj

A mesh: a gripper (with its .DAT) or a cell element

File ▸ Import ▸ Gripper, add ▸ Cell Component (File)

.DAT

A gripper’s data: its cups or TCP

read with the gripper’s mesh

.ini

A cell component’s data: Type=Pallet and its height

read with the component’s mesh

.csv

Collision triangles

settings ▸ Collision Triangles ▸ Import CSV…

Export CSV in the triangle dialog

.rbc

The robot program

nc code, Post-process

.LS

The FANUC program

RobotPost, after nc code or Post-process

.fcell

An old cell format

no longer opens

Folders and settings files

In the installation folder (normally C:\Metamation\FRobot):

Folder What it holds

CellConfigs\<robot>

The cell configs of each robot; Default.curl loads at start

Output

The robot programs (.rbc)

grippers

The gripper catalog, the cup types and the priorities

robots, CellItems, Machines

The robot models and the libraries

Samples

The sample files

In Bin, next to FRobot.exe:

File What it remembers

robot.sel

The robot you used last

robot_defaults.json

Home, the TCP and the mounted tool

panels.cfg

Where you left the panels

postproc.cfg

The post-processor’s location

machine.cfg

The RBC format switch

Parts kept inside solutions are unpacked to %LOCALAPPDATA%\FRobot\Parts when a solution opens.

Not remembered between sessions:

  • the Display switches;

  • the World Frame tick;

  • the rail’s width;

  • the recent files;

  • the planner choice;

  • the experimental switches.

Glossary

Term Meaning

Cell

The robot and everything around it

Cell config

A saved cell (.curl), kept per robot

Cell element

A station or fixture in the cell

Continuous run

Playing every part of the stack onto the deposit, place after place

Cycle

The robot’s moves for one part, from Home and back to Home

Deposit grid

The places on a Deposit station that parts are put down on, one after another

Flange

The robot’s last face, where the gripper is mounted

Home

The pose every cycle starts and ends at

Joint move (J, PTP)

A move where each axis turns its own shortest way

Linear move (L, LIN)

A move where the TCP goes in a straight line

Overturner

A station where the part is put down and picked up from its other side

Phase

The part of the cycle at one station: P, C, L, U, R or D

Phase strip

The row of phase cells in the title bar

Regrip

Taking the part again with another grip, at the Overturner

Role

What a cell element is for: Pickup, Deposit, Centering Table …

RRT

A sampling search that finds a way round an obstacle where the rules can’t

Singularity

A pose where two wrist axes line up and the robot moves badly

Solution

A part’s whole cycle in a cell, with its gripper; saved as .fr

Station user frame

An element’s position and rotation (X, Y, Z, W, P, R) in the robot’s world frame

TCP

Tool centre point: the point of the gripper the program moves

Waypoint

One pose of the robot in the cycle

World frame

The robot’s base coordinate system
