Troubleshooting

Troubleshooting

Tip
 Some actions report only in FRobot’s status line, which shows at the foot of the Part and Frames panels. If a click seems to do nothing, open settings ▸ Part and read the green line at the bottom.

Messages

You see It means What to do

Path planning — out of reach, listing waypoints such as Pickup · PickContact: out of reach — J5 … above max …

The robot can’t reach those waypoints within its joint limits

Move the station closer, lower the stack or move the robot, then recompute. See Creating the solution.

A red cell in the phase strip

An error in that phase: a collision, or a pose out of reach

Hover the cell to read it: The phase strip

A yellow cell in the phase strip

A warning: close to a joint limit or the wrist singularity, or a swing within 10 mm of an element with the role Other or of the Overturner

Check it in the simulation; often it can stay

No grippers found for … : reason. … kept

No gripper in the catalog can hold this part

Check the reason: the part too heavy, too small or too holed. Import a suitable gripper: Importing a gripper.

Import a sheet on a pickup pallet, then generate the cycle. (status line)

Pick & Place Tech found no pallet in the cell

Add a pallet (only a pallet can be the pickup): Adding stations. On a new installation, open a cell config first: FRobot starts on FanucX, whose cell is empty.

Build the pick-&-place solution first (Pick & Place Tech).

Post-process was clicked without a solution

Create the solution first

No waypoints to edit — generate a cycle first. (status line)

W was pressed without a solution

Create the solution first

✖ Post-processor not found: … Set it in Settings ▸ Machine Defaults.

RobotPost isn’t where FRobot looks for it

Machine Defaults

Import a gripper mesh with a paired .DAT (it defines the cups / TCP)

A gripper mesh was imported without its .DAT file

Put the .DAT next to the mesh, with the same name

The view is empty after 3D Model; 'file' has no closed profile to extrude (status line)

The drawing has no closed outline

Close the outline in your CAD program; click 2D Part to see the drawing again

⚠ Cell elements overlap: A ↔ B (status line), elements drawn red

Two cell elements take up the same space

Move one of them in the Frames panel

… files are no longer supported — open a solution (.fr) or a cell config (.curl)

The file type can’t be opened, for example an old .fcell

Open a .fr, .curl, .dxf or .geo

Open solution failed: … or Not a solution file

The .fr file is damaged or not from FRobot

Use another copy of the file

FRobot encountered a problem

An unexpected error. In this version it shows for About FRobot, and may show when you close the TCP Offset or Add Collision Triangle dialog.

Click OK; FRobot carries on. If it happens elsewhere, note what you did.

Things that seem wrong

You notice Why What to do

The view is empty after starting

The robot and cell are loaded but hidden until you open a cell config or a solution

Open a cell config, or a part and create its solution

A Pickup role on my fixture does nothing

Only a pallet can be the pickup

Use a library pallet, or give your component a Type=Pallet .ini

My gripper changed after opening a cell config or switching the robot

The config brings its own gripper, or FRobot chose again

Pick the gripper again: Choosing a gripper yourself

The phase strip still shows the old colours after a gripper, TCP, thickness or station change

Those changes don’t re-plan or re-check the cycle

Click recompute

add is missing from the rail

add shows for a new cell and once a solution exists

Use File ▸ Import ▸ Cell Component, or create the solution first

The robot isn’t shown in the bottom bar

It shows once a solution exists

Use database ▸ Robots to switch the robot

My edited waypoints are gone

Something planned the cycle again (recompute, a pickup or grip change, Next heading)

Edit waypoints last; see Waypoints

A moved station has not changed the cycle

Moving a station doesn’t re-plan

Click recompute

The obstacle box is no longer avoided

It is an obstacle only while shown, and showing it isn’t saved

Tick Show obstacle box again

The collision triangles are gone, or still there in another cell

Triangles are not saved, and they stay until you remove them or restart

Import them again from their CSV file, or remove them with ×

A cell config is missing a station

It uses a library item, machine or file that isn’t on this PC; a short note at the bottom right of the 3D view said so

Install the item, or replace the station

The tray under the phase strip disappeared

It hides while another program is in front

Click into FRobot

Ctrl+S, Ctrl+O and the other menu shortcuts do nothing

Not wired up in this version (Ctrl+E works, over the 3D view)

Use the menus; see Not available yet
