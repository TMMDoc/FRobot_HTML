Cell configs

A cell config stores a cell so you can use it again with other parts. It is a .curl file, kept per robot in the installation folder under CellConfigs\<robot>.

Saving a cell

  1. Choose File ▸ Save Cell Config.

  2. Type a name and click Save, or press Enter.

FRobot writes CellConfigs\<robot>\<name>.curl and confirms with a toast, for example Cell config saved: FlexCell.curl. You can’t choose another folder.

Note
 The name box starts with the current cell’s name, often Default, and an existing config of that name is replaced without asking. Type a new name unless you mean to replace it.

  • Name it Default to make it the cell that robot starts with.

  • Before a solution exists, File ▸ Save and File ▸ Save As…​ also save a cell config.

  • Once a solution exists, File ▸ Save Cell Config saves the cell and the part, but not the cycle. File ▸ Save saves the whole solution: see Solutions.

Note
 Changes to a cell without a part (stations moved or added) don’t count as unsaved, so FRobot does not ask about them when you close it. Save the cell config before you close.

What a cell config holds

  • The robot.

  • Every cell element: its library item, machine or file, with its role and frame, its palletizing grid and its place on the machine bed.

  • Home: the pose and the joint values.

  • The tool: the gripper and its .DAT file, how it is mounted, and the TCP.

  • The obstacle box’s position.

  • The STEP parts and where they are placed.

  • The part, if one is open: a copy of its drawing file, its thickness and stack, and its positions and grips at each station.

What it does not hold

  • The collision triangles.

  • Whether the obstacle box is shown.

  • The Display switches.

  • The planner chosen in Recompute.

  • The Machine Defaults (they belong to the installation).

Opening a cell config

There are three ways:

  • File ▸ Open…​ or open, choosing a .curl file;

  • the robot selector (the robot in the bottom bar, or the layers badge in the Workflow window), clicking one of the configs listed under a robot;

  • a cell config named Default is loaded when FRobot starts on that robot.

What happens:

  • The cell config loads into the screen you are on, and the robot switches to the config’s robot.

  • If a part is open, it stays and FRobot plans it in the new cell straight away. This happens without asking, also over a solution: waypoints you edited by hand are lost, and the gripper may be chosen again.

  • If the config was saved with a part, that part is loaded and planned.

  • Otherwise the cell is shown on its own.

  • The Workflow window: opening from File ▸ Open…​ opens it, or closes it if it was open. A config loaded from the robot selector leaves it as it is.

Note
 If the cell config uses a library item, machine or file that is not on this PC, that element is left out. Only a short note at the bottom right of the 3D view says so. Check that every station is there.
Note
 A later setup of FRobot does not overwrite the CellConfigs folder, and uninstalling leaves it in place.
