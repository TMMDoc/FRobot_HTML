Thickness, material and the stack

Thickness, material and the stack

Thickness

The sheet thickness shows in the bottom bar once the 3D part exists, for example 1 mm.

  1. Click it.

  2. Type the thickness and press Enter.

FRobot rebuilds the part with that thickness. Leaving the box without Enter puts the old value back.

With a solution open, the cycle is not planned again for the new thickness: click recompute.

Material

The material comes from the drawing and can’t be changed in FRobot: see Importing the part.

The stack on the pickup pallet

The parts come stacked on the pickup pallet. The stack’s height is the thickness times the number of parts.

  • A new 3D part starts with a stack of 5.

  • Change the number with Layers in the Pickup panel, from 1 to 999: see The pickup.

The robot always picks from the top of the stack. In a continuous run it takes the parts one after another: see Simulation.

Note
 When you open a cell config while a drawing is open but not yet made 3D, the part takes the thickness and stack stored in that cell config (or 1 mm and 5 parts). For a GEO part this replaces the file’s own thickness.

The solution’s name

The name in the bottom bar is the solution’s name:

  • it starts as the drawing’s name;

  • after you save, it is the solution file’s name.

To rename the solution:

  1. Click the name, type the new one, and press Enter (or just leave the box).

  2. The next File ▸ Save writes the solution as <new name>.fr.

    • If the solution was saved before, it goes in the same folder, and the earlier file stays as it was. If a file with the new name exists, FRobot asks before replacing it.

    • If it was never saved, the Save dialog opens with the new name filled in.

Renaming changes neither the drawing file nor the robot program: the program keeps the drawing’s name, Output\<drawing name>.rbc.
