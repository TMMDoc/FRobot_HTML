Not available yet

This version of FRobot shows some menu items and controls that are not working yet. Most of them only show a short message such as … not in this prototype. They are listed here so you know what to expect, and what to use instead.

Menus

Item What happens Instead

File ▸ New ▸ Drawing

A message only

File ▸ Export ▸ Cell Config.

A message says Cell configuration exported, but nothing is exported

File ▸ Save Cell Config

File ▸ Import ▸ Cell Config.

A message only, Import Cell Config — choose a file; no file dialog opens

File ▸ Open…​ with a .curl file

File ▸ Import ▸ Suction Cup

Opens Import Tool. Don’t use it: it replaces the mounted gripper with a plain tool mesh (no cups), fits a new TCP, and stops automatic gripper choice.

Cup types come with the gripper catalog

Greyed out
