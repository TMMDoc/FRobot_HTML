Importing a gripper

A gripper is imported from two files, side by side in one folder:

  • the mesh (.stl or .obj): the gripper’s shape. Model it with its origin on the face that mounts to the robot’s flange.

  • the .DAT file: the gripper’s data, such as its suction cups (type and position) or its TCP.

FRobot pairs them by name: ConVac_270x200.stl goes with ConVac_270x200.DAT. Without a match it takes the first .DAT file in the folder.

Importing

  1. Choose one of:

    • File ▸ Import ▸ Gripper;

    • Import Gripper… in the Gripper Database (database ▸ Grippers);

    • Import Gripper… in the Tooling panel (settings ▸ Tooling).

  2. Pick the mesh file.

FRobot does three things:

  • it converts the gripper into the catalog, in the grippers folder of the installation, under the name given on the .DAT file’s NAME= line;

  • it adds the gripper to the priority list, at priority 1;

  • it mounts the gripper, assigned by hand.

The status line confirms it, for example Gripper 'ConVac_270x200' converted into the catalog (4 cup(s)) and mounted. The new gripper then shows in the Gripper Database and in every gripper list.

Note
 A gripper whose name is already in the catalog replaces that entry. The replacement keeps only what the .DAT file holds: the entry’s own safety factor and flags are lost. The samples in Samples\SampleGrippers (ConVac_270x200 and FCVac_6cup) are already in the catalog. To try an import with them, copy one and give it a new NAME= in its .DAT file first.
Note
 A mesh without a .DAT file is refused: Import a gripper mesh with a paired .DAT (it defines the cups / TCP).
Note
 A .DAT file has no weight line, so an imported gripper is recorded with no weight. Keep that in mind when the robot’s payload is close.

Suction cups

The cup types are kept in the catalog (grippers\cups) with their sizes and holding forces, and they are drawn at their real size.

  • A cup type the catalog doesn’t know is drawn as a plain ring. Its diameter is taken from the number in its name. It has no holding force, so a gripper with such cups is never chosen automatically. Pick it by hand, or add the cup type to the catalog.

  • The Suction cups switch in the Display panel shows or hides the cups.
